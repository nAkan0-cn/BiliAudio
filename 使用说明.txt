BiliAudio — B站音频下载器 1.0

使用方法
1. 双击 BiliAudio-v1.0.exe，无需安装 Python 或 FFmpeg。
2. 粘贴普通 B站视频链接、BV号，或含 b23.tv 链接的分享文字。
3. 选择保存文件夹。默认：当前用户的 Music\BiliAudio。
4. 选择“原始音频”或“MP3”，点击“开始下载”。
5. 点击“打开保存文件夹”查看结果。

格式与分P
原始音频：下载网站提供的独立音轨，通常为 M4A，不再次压缩。
MP3：转换为高质量可变码率 MP3，同时保留原始音频。
默认只下载链接指定的分P；未指定时下载第一P。
勾选“下载全部分P”后，下载同一投稿内全部分P，不扩展到UP主的其他视频。
同名文件不覆盖。取消后可能留下 .part 或 .converting.mp3 文件，重试可续传或重新转换。
进度条表示当前音轨的下载进度，多分P时会逐项重置。

登录内容
公开内容通常不需要 Cookies。需要登录时，可导入自己的 Netscape 格式 cookies.txt。
程序不读取浏览器密码；Cookies 仅用于站点请求，临时副本在任务结束后删除。
强制退出可能留下系统临时目录中的副本。不要分享自己的 Cookies 文件。
软件不绕过付费、会员或地区访问权限。

常见问题
出现 403、412、登录提示：确认浏览器能够正常播放，稍后重试或导入自己的 Cookies。
没有可用音轨：部分视频没有独立音轨，此版本不会退回下载整个视频。
下载失败：原始错误会显示在窗口日志中；已完成的文件会保留。
站点接口变化可能导致解析失败，需要更新 yt-dlp 并重新打包。
这是未进行代码签名的个人工具，Windows 可能提示未知发布者。

系统与源码
适用于 Windows 10/11 64位，需要联网下载。
GitHub 仓库：app.py、requirements.txt 和 build.ps1 位于仓库根目录。
完整发行版压缩包：源码及打包脚本位于 BiliAudio-source 文件夹。
开发时安装 Python 3.11+，执行 build.ps1；产物在 dist\BiliAudio-v1.0.exe。
